Added `check_hed_lab_metadata_exists`, `check_hed_annotations_valid`, and `check_hed_annotations_warnings` for HED annotations written with the `ndx-hed` extension. Each table that carries HED is validated by `ndx-hed`, including the HED of its `MeaningsTable`s and of each row as a whole; tables without HED are not read. Validating the annotations requires the extension, which is a new optional dependency installed with `pip install nwbinspector[hed]`.
