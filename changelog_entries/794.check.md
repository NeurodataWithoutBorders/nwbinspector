Added `check_identical_time_series` and `check_redundant_time_series_copies`, which flag TimeSeries in one file that hold identical data. The first (CRITICAL) covers series of different kinds, such as a processed series identical to one in acquisition, and the second (BEST_PRACTICE_VIOLATION) covers redundant copies of the same kind, which should be stored once and linked. HDF5 links to the same dataset are not reported.
