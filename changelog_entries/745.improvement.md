`check_negative_spike_times` and `check_units_table_duration` now read only the first and last spike of each unit through a shared helper, `check_ascending_spike_times` reads at most `nelems` spike times per unit directly through the index array instead of materializing each unit's full train, and `check_spike_times_without_nans` scans the spike times in fixed-size chunks. None of these checks loads every spike time in the file into memory any more.
